# INFINITY｜无限定制PPT 正式版 V1.0

## 本地查看
解压网站部署包，双击 `index.html`，不要单独移动 HTML 文件。也可使用单文件体验版（另行交付）。体验版为离线浏览，正式发布应使用部署包中的文件，以获得按需加载效果。

## 发布
1. 确认所有展示内容拥有公开展示授权；检查商业数据、联系方式、第三方二维码及个人信息。如有敏感页面，请删除对应公开图片并同步调整案例配置，不能仅从精选页中隐藏。
2. 此版本已配置微信号 `17610693080`，首页和案例详情均展示该号码，并支持一键复制。未提供微信二维码，不展示二维码占位。后续可在 `config.js` 修改联系方式。
3. 将本目录全部网页文件及 `assets` 目录上传到静态网站托管服务，保持相对路径。绑定长期使用的 HTTPS 域名。无需数据库或后端服务。若面向中国大陆用户，应选择实际可达的托管服务，并按照服务商要求处理备案及其他上线手续（如适用）。
4. 通过 iPhone、安卓及微信内置浏览器检查首页、案例筛选、所有案例、高清浏览、分享及联系方式。
5. 使用正式 HTTPS 首页 URL 生成推广二维码并实测扫码，后续更新网站无需更换固定网址对应的二维码。

## 文件结构
- index.html：网站入口
- styles.css：响应式布局及视觉样式
- app.js：分类、案例详情、查看完整作品、高清浏览、咨询及分享交互
- config.js：联系方式设置
- projects.js：案例标题、分类、总页数、精选页码
- assets/<id>/cover.webp：960×540 封面
- assets/<id>/01.webp 等：1920×1080 高清页面
- assets/<id>/preview/01.webp 等：960×540 轻量页面（自动按设备选择合适分辨率）

## 新增案例
在 assets 中创建新的英文 ID 目录，按上述文件命名规则保存封面、页面及轻量预览图；在 projects.js 的数组中新增 id、title、category、pages、featured 字段。现有分类为品牌分析、商业方案、影视宣发。新增分类时同时修改 app.js 的 categories。保留原有案例 ID 可保持已分享链接有效。

## 测试范围
已校验6套案例共185张高清图及185张轻量图；本地 Chromium 以320、390、1440像素视口测试首页布局、筛选、案例详情、展开、翻页、缩放、关闭、咨询入口，无脚本异常。测试采用内联本地素材方式。公网托管、HTTPS、微信实机访问及实际分享、扫码尚未验证。
